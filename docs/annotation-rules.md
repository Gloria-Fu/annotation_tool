# Skill 标注规则 v1

## 范围与格式

完整已实现模板保存在 frontend/src/features/workbench/skillDefinitions.ts。
开放列表单独保存在 frontend/src/features/workbench/enabledSkills.ts 的 ENABLED_SKILLS。
增删开放列表条目即可控制选择项与编辑权限，无需删除模板或本规则文档。
列表顺序决定下拉选项顺序；当前仅开放 Pick、Place，尚未实现或关闭的 Skill 不能直接加入列表。
关闭的 Skill 历史记录仍可显示模板和原数据，但不可编辑、保存或提交/审核通过；
可以退回修改或主动切换至开放 Skill。空列表表示不开放任何新的 Skill。

前端仅开放 Pick、Place。先选择 Skill，再加载句式填空。
字段标签始终位于控件上方，示例仅作为 placeholder，不自动保存为答案。
物体名称重复出现时自动引用。颜色、材质、形状分别填写，均可选。
每个片段标记核心关键瞬间，保存帧号、视角及归一化画面坐标。
Pick 按操作手分别记录夹持瞬间，双手可以在同一个片段内使用不同帧，不强制拆段。
靠近过程、接触和结束过程以文字描述，不拆成多个关键节点。

## 通用字段

- 操作手：左手、右手、双手。
- 夹爪初始位置：用“参照物 + 相对方位 + 局部区域”描述动作开始时夹爪的位置，例如“餐桌右侧边缘外侧”。
- 初始状态：张开、闭合、无法判断；双手时分别填写左右状态。
- 靠近目标位置 / 目标位置：用参照物、具体方位和局部区域描述要到达的位置，例如“白色桌面右上角的铅笔盒前方”或“托盘内靠近左后角的位置”。Place 中表示释放前物体/夹爪到达的位置。
- 物体所在位置：用承载物和具体方位描述物体当前所在位置，例如“白色桌面右上角的铅笔盒”。Place 初始已持握物体，不要求此字段。
- 物体名称；颜色、材质、形状可选。
- 相对姿态：平行、垂直、倾斜、无法判断。
  姿态指夹爪接近方向与物体或目标支撑面的关系，不指两指连线。
- 接触部位：例如物体两侧、把手两侧。
- 夹爪动作：张开、闭合、保持张开、保持闭合、无法判断，不预设必然闭合。
  双手时分别填写左右动作。
- 补充说明：选填。不能从画面判断的信息不猜测，文本填写“无法判断”。

## Pick / 拾取

定义：夹爪夹持住物体，当前范围到夹住时结束，不要求离开支撑面或后续搬运。
关键帧：物体被夹爪夹持住的瞬间。
需要标记：每只操作手在其夹持瞬间的左夹和右夹，两个夹指必须分别标坐标或明确选择“不可见”。
同一只手共用一帧 HEAD 画面；两个可见夹指坐标不能重合。
单手只显示一个标记入口；双手显示“左手”和“右手”两个入口。
双手同时夹持时，停在同一帧依次处理两个入口；非同时夹持时，在各自帧分别处理。
左右夹指当前视角下同一个夹爪的两侧夹指，不指左手和右手两个机械臂。
无论夹指是否可见，都必须标出左右夹的大致位置；不可见时根据画面估计位置，并将该夹指标为不可见。
标记入口打开 HEAD 当前帧的精细标记弹窗，帧号固定；支持缩放、平移及拖动标记点。
当前手的两夹完成后一起确认保存，取消不更改原标记，另一只手不受影响。
两个夹指都不可见时允许确认，但仍需要两个估计坐标。
其他帧或视角的旧点不会混入当前帧。
画面放大不改变归一化坐标，也不进行 AI 增强或内容补全。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}。
靠近位于{物体所在位置}的{物体描述}，夹爪以相对{物体}{相对姿态}的姿态，
{夹爪动作}夹爪，夹持住{物体}的{接触部位}。
{抬起夹爪}{收尾动作和状态}。

Pick 不再填写靠近目标位置、原支撑面和物体结束位置；历史字段保留但不参与新句生成和校验。
物体名称首次填写后会自动带入“相对物体”和“夹持物体”；两处均可单独修改。
“初始夹爪状态”默认张开，“夹爪动作”默认闭合。
“收尾动作和状态”必填，选项为“向上抬起”“无动作”“其他”；选择“其他”时必须补充填写具体动作和状态。
选择“向上抬起”时保留尾句，抬起夹爪默认与“操作手”一致；选择“无动作”时句子在接触部位后结束。

Pick 允许将一次尝试标记为成功、失败或待判定。失败时进入独立的失败事件面板，必须选择结构化失败原因；选择“夹爪向某方向偏移”时还必须填写偏移方向。失败不套用 Pick 成功句式，不要求操作手、初始位置、物体位置、姿态、接触点、夹爪动作或关键帧；失败后的复杂状态通过自由说明记录，生成句子不得表述为已经成功夹持。

## Place / 放置

定义：将持握物体置于目标支撑面并释放。
关键帧：夹爪完全张开的时刻；若边张开边移动，取移动前张开最大的帧。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}，持握{物体描述}。
夹爪以{相对姿态}的姿态，将物体移动至{目标位置}，释放方式为{释放方式}，{夹爪动作}夹爪，物体最终位于{放置位置}。
{抬起夹爪}{收尾动作和状态}。
“初始夹爪状态”默认闭合，“夹爪动作”默认张开。
“释放方式”必填，选项为“接触支撑面后释放”“空中释放后落至目标位置”“无法判断释放方式”。
“收尾动作和状态”必填，选项为“向上抬起”“无动作”“其他”；选择“其他”时必须补充填写具体动作和状态。
选择“向上抬起”时保留尾句，抬起夹爪默认与“操作手”一致；选择“无动作”时句子在释放夹爪后结束。
Place 只记录夹爪完全打开的关键帧帧号，不标记左夹和右夹位置。

Place 允许将一次尝试标记为成功、失败或待判定。失败时进入独立的失败事件面板，必须选择结构化失败原因；失败不套用 Place 成功句式，不要求操作手、初始位置、持握物体、靠近目标、姿态、放置位置、释放动作或关键帧；失败后的复杂状态通过自由说明记录，生成句子不得表述为已经成功放置。

## 失败尝试与重试

失败尝试和后续重试必须分别建立片段，按时间顺序保留。失败片段在确认失败的帧结束；重试片段从下一帧开始，并保留相同 Skill 和物体上下文，但清空旧关键帧、失败原因和需要重新确认的动作字段。
失败段只要求失败原因；“其他”原因需要填写失败情况说明，偏移原因需要填写偏移方向。失败片段不需要标关键帧；失败后的复杂状态说明可以直接写入失败事件面板的自由说明，不因成功句式字段缺失而阻塞确认。
重试片段保存 retry_of 和 attempt_group_id，并要求填写恢复动作。目标点名称和编号可以结构化保存，用于生成“重新对准目标点（point1）”等文本。
时间轴按结果显示状态：成功、失败、待判定；失败片段使用失败样式。普通分段不会替代重试操作，因为普通分段可能复制上一段的精细标注。

## Grasp / 抓握

定义：形成稳定夹持，不要求物体离开支撑面。
关键帧：夹爪形成稳定夹持、物体开始被控制的瞬间。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}，向{靠近目标位置}移动。
靠近位于{物体所在位置}的{物体描述}，夹爪以{相对姿态}的姿态，
在其{接触部位}{夹爪动作}夹爪，形成稳定抓握。
不要求物体结束位置。

## Push / 推动

定义：通过接触施加推力，使物体移动。
关键帧：物体因推动第一次开始移动。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}，向{靠近目标位置}移动。
靠近位于{物体所在位置}的{物体描述}，夹爪以{相对姿态}的姿态，
{夹爪动作}并接触其{接触部位}，向{推动方向}推动物体，使其移动至{物体结束位置}。

## Pull / 拉动

定义：建立接触或控制后施加拉力，使物体移动。
关键帧：物体因拉动第一次开始移动。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}，向{靠近目标位置}移动。
靠近位于{物体所在位置}的{物体描述}，夹爪以{相对姿态}的姿态，
在其{接触部位}{夹爪动作}夹爪，向{拉动方向}拉动物体，使其移动至{物体结束位置}。

## 保存、校验与兼容

草稿允许未填完。新模板提交或审核通过时，必须填写当前 Skill 的所有非选填字段，
且关键点帧位于片段的 [start_frame, end_frame) 范围内。
退回修改不受完整性限制。
Skill 英文标识保持不变；结构化字段保存在 fine_annotation.template_values，
template_version=1；生成句子保存在 segment.text。
切换 Skill 保留已填写字段，但只渲染、校验和输出当前模板字段；关键点必须重新标记。
旧数据不自动转换、不丢弃字段；其他 Skill 显示未开放提示，需主动选择开放 Skill 才可编辑。
旧版无模板的开放 Skill 可继续查看，编辑后进入 v1 模板校验。
接口仍为 segments.v1 通用 JSON，不修改原始数据或数据库结构。
Pick 按操作手存于 fine_annotation.gripper_keyframes.left/right；外层 left/right 指左手/右手。
每组包含 frame、view，以及表示左夹/右夹的 left/right。可见夹指为
{visibility: "visible", x, y}，不可见夹指为 {visibility: "invisible"}，不存坐标。
x/y 是相对于视频实际内容的 [0,1] 归一化坐标。其他 Skill 继续使用 keyframe_point 单点。
Pick、Place 的尝试结果保存在 fine_annotation.outcome，取值为 pending、success、failure。
失败原因保存在 failure_reason_code；夹爪偏移时额外保存 failure_direction，其他补充信息保存
在 failure_detail。重试片段在 Segment 上保存 retry_of、attempt_group_id，恢复动作和目标点
信息保存在 fine_annotation.recovery_action、target_point_id、target_point_label。
历史 keyframe_point/keyframe_points 保留，但不推断操作手归属；v1 模板提交前需通过新入口重新确认。
切换操作手不把左手坐标转给右手；已保存分组保留，仅显示和校验当前选择的操作手。
