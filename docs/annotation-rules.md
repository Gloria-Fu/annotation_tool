# Skill 标注规则 v1

## 范围与格式

完整已实现模板保存在 frontend/src/features/workbench/skillDefinitions.ts。
开放列表单独保存在 frontend/src/features/workbench/enabledSkills.ts 的 ENABLED_SKILLS。
增删开放列表条目即可控制选择项与编辑权限，无需删除模板或本规则文档。
列表顺序决定下拉选项顺序；目前保持五项全部开放，尚未实现的 Skill 不能直接加入列表。
关闭的 Skill 历史记录仍可显示模板和原数据，但不可编辑、保存或提交/审核通过；
可以退回修改或主动切换至开放 Skill。空列表表示不开放任何新的 Skill。

前端仅开放 Pick、Place、Grasp、Push、Pull。先选择 Skill，再加载句式填空。
字段标签始终位于控件上方，示例仅作为 placeholder，不自动保存为答案。
物体名称重复出现时自动引用。颜色、材质、形状分别填写，均可选。
每个片段标记核心关键瞬间，保存帧号、视角及归一化画面坐标。
Pick 按操作手分别记录夹持瞬间，双手可以在同一个片段内使用不同帧，不强制拆段。
靠近过程、接触和结束过程以文字描述，不拆成多个关键节点。

## 通用字段

- 操作手：左手、右手、双手。
- 夹爪初始位置：场景中的位置，例如货架前侧。
- 初始状态：张开、闭合、无法判断；双手时分别填写左右状态。
- 靠近目标位置：场景参照位置，例如货架右上方，不混用无参照的画面方向。
- 物体所在位置：例如货架右侧；Place 初始已持握物体，不要求此字段。
- 物体名称；颜色、材质、形状可选。
- 姿态参考：物体长轴或支撑面；相对姿态为平行、垂直、倾斜、无法判断。
  姿态指夹爪接近方向与参考轴或面的关系，不指两指连线。
- 接触部位：例如物体两侧、把手两侧。
- 夹爪动作：张开、闭合、保持张开、保持闭合、无法判断，不预设必然闭合。
  双手时分别填写左右动作。
- 补充说明：选填。不能从画面判断的信息不猜测，文本填写“无法判断”。

## Pick / 拾取

定义：夹爪夹持住物体，当前范围到夹住时结束，不要求离开支撑面或后续搬运。
关键帧：物体被夹爪夹持住的瞬间。
需要标记：每只操作手在其夹持瞬间的左夹和右夹，两个夹指必须分别标坐标或明确选择“不可见”。
同一只手共用一帧 HEAD 画面；两个可见夹指坐标不能重合。
单手只显示一个标记入口；双手显示“左手”和“右手”两个入口。
双手同时夹持时，停在同一帧依次处理两个入口；非同时夹持时，在各自帧分别处理。
左右夹指当前视角下同一个夹爪的两侧夹指，不指左手和右手两个机械臂。
标记入口打开 HEAD 当前帧的精细标记弹窗，帧号固定；支持缩放、平移及拖动标记点。
当前手的两夹完成后一起确认保存，取消不更改原标记，另一只手不受影响。
两个夹指都不可见时允许确认；取消“不可见”后须重新标点，不恢复猜测坐标。
其他帧或视角的旧点不会混入当前帧。
画面放大不改变归一化坐标，也不进行 AI 增强或内容补全。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}。
靠近位于{物体所在位置}的{物体描述}，夹爪以相对{姿态参考}{相对姿态}的姿态，
在其{接触部位}{夹爪动作}夹爪，夹持住物体。

Pick 不再填写靠近目标位置、原支撑面和物体结束位置；历史字段保留但不参与新句生成和校验。

## Place / 放置

定义：将持握物体置于目标支撑面并释放。
关键帧：物体第一次接触目标支撑面。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}，持握{物体描述}，向{靠近目标位置}移动。
夹爪以相对{姿态参考}{相对姿态}的姿态，将物体放置在{放置位置}，
待其受到支撑后{夹爪动作}夹爪。随后夹爪移动至{夹爪结束位置}。
最后一句选填；物体放置位置与夹爪结束位置不得混淆。

## Grasp / 抓握

定义：形成稳定夹持，不要求物体离开支撑面。
关键帧：夹爪形成稳定夹持、物体开始被控制的瞬间。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}，向{靠近目标位置}移动。
靠近位于{物体所在位置}的{物体描述}，夹爪以相对{姿态参考}{相对姿态}的姿态，
在其{接触部位}{夹爪动作}夹爪，形成稳定抓握。
不要求物体结束位置。

## Push / 推动

定义：通过接触施加推力，使物体移动。
关键帧：物体因推动第一次开始移动。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}，向{靠近目标位置}移动。
靠近位于{物体所在位置}的{物体描述}，夹爪以相对{姿态参考}{相对姿态}的姿态，
{夹爪动作}并接触其{接触部位}，向{推动方向}推动物体，使其移动至{物体结束位置}。

## Pull / 拉动

定义：建立接触或控制后施加拉力，使物体移动。
关键帧：物体因拉动第一次开始移动。

{操作手}夹爪初始位于{初始位置}，状态为{初始状态}，向{靠近目标位置}移动。
靠近位于{物体所在位置}的{物体描述}，夹爪以相对{姿态参考}{相对姿态}的姿态，
在其{接触部位}{夹爪动作}夹爪，向{拉动方向}拉动物体，使其移动至{物体结束位置}。

## 保存、校验与兼容

草稿允许未填完。新模板提交或审核通过时，必须填写当前 Skill 的所有非选填字段，
且关键点帧位于片段的 [start_frame, end_frame) 范围内。
退回修改不受完整性限制。
Skill 英文标识保持不变；结构化字段保存在 fine_annotation.template_values，
template_version=1；生成句子保存在 segment.text。
切换 Skill 保留已填写字段，但只渲染、校验和输出当前模板字段；关键点必须重新标记。
旧数据不自动转换、不丢弃字段；其他 Skill 显示未开放提示，需主动选择开放 Skill 才可编辑。
旧版无模板的开放 Skill 可继续查看，编辑后进入 v1 模板校验。
接口仍为 segments.v1 通用 JSON，不修改原始数据或数据库结构。
Pick 按操作手存于 fine_annotation.gripper_keyframes.left/right；外层 left/right 指左手/右手。
每组包含 frame、view，以及表示左夹/右夹的 left/right。可见夹指为
{visibility: "visible", x, y}，不可见夹指为 {visibility: "invisible"}，不存坐标。
x/y 是相对于视频实际内容的 [0,1] 归一化坐标。其他 Skill 继续使用 keyframe_point 单点。
历史 keyframe_point/keyframe_points 保留，但不推断操作手归属；v1 模板提交前需通过新入口重新确认。
切换操作手不把左手坐标转给右手；已保存分组保留，仅显示和校验当前选择的操作手。
